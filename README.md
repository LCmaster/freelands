# Freelands

An open-source, 3D isometric fantasy MMORPG built for the web.

Freelands is a shared fantasy world where players are free to explore, fight, craft, trade, discover ancient places and forge their own adventures.

No predefined classes. No predetermined destiny. Your journey is yours to shape.

## Tech Stack

- **Client:** SvelteKit, TypeScript, Three.js
- **Server:** Go
- **Communication:** WebSocket
